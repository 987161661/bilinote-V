## 不止“视频转 Markdown”

原版 BiliNote 擅长把一条视频转成笔记。威力加强版把它扩展成完整工作流：

```text
发现视频  →  加入队列  →  批量生成  →  AI 校对  →  收录合集 / 知识库  →  随时回看与问答
```

不必在收藏夹、聊天记录和零散 Markdown 之间来回翻找。每条值得保留的视频，都能沉淀为可编辑、可校对、可归档的笔记。

## 为三种常见场景而做

### 想系统学一门技能

选择 **智能教程**。它先识别读者要解决的问题、关键判断和行动顺序，再写成可复做的教程；并结合上下文修正自动听写中高置信度的同音词与术语错误。

### 想一次处理一批收藏视频

打开 **批量任务**：像浏览 B 站或 YouTube 一样检索、翻页、按分区浏览或查看关注创作者。点击视频标题即可加入处理队列，进度、已处理状态与重试一目了然。

### 想把笔记真正用起来

将笔记放进 **合集** 或 **知识库**。合集适合按主题归档与预览；知识库适合积累后直接提问。预览页仍可校对、编辑、导出和管理。

## 威力加强版带来的关键能力

| 原版的单条生成体验 | 威力加强版的工作台体验 |
| --- | --- |
| 输入一个视频链接，生成一篇笔记 | 在 **工作台** 统一管理新建笔记、批量任务、合集、知识库、智能体与用量 |
| 手动逐条处理视频 | 视频流、搜索、分区、分页、创作者筛选与 **处理队列** |
| 生成后自行判断质量 | **校对栏** 标记原文疑点，点选查看 AI 建议，不会悄悄覆盖原稿 |
| 单一模型配置 | **智能体管理**：为解析、校对、知识库问答分别选择模型、标签、Skills 与高级参数 |
| 配置分散、任务间不一致 | 批量任务复用“新建笔记”的语言、目录、截图、总结、视觉理解和输出规格 |
| 普通教程格式 | **智能教程**：面向读者组织，而非机械复述素材 |

## 两分钟开始使用

1. 前往 [Releases](https://github.com/987161661/bilinote-V/releases) 下载最新的 Windows `.exe` 安装包。
2. 双击安装，启动 **BiliNote 威力加强版**。
3. 在「AI 模型设置」中填入自己的模型供应商和 API Key。
4. 粘贴视频链接开始生成，或前往「批量任务」建立队列。

> 首次使用本地转写时，应用会按需下载 Whisper 模型；也可改用在线转写服务。

## 你的数据在哪里？

笔记、截图、模型、账号授权和个人配置只保存在本机：`%LOCALAPPDATA%\BiliNote-Power`。

安装包不预置任何 API Key、B 站 Cookie 或个人数据。

## 保持最新

应用启动时会检查本仓库的 Releases；发布新版后，右下角会出现 **“发现新版本，立即更新”**，点击即可下载新版安装包。
