# BiliNote 威力加强版

> 面向个人知识工作流的本地视频笔记工作台。在 BiliNote 原版的“单视频转笔记”基础上，补齐了批量处理、资料组织、智能体与读者导向的智能教程能力。

## 相比原版，新增了什么？

| 能力 | BiliNote 威力加强版 |
| --- | --- |
| 工作台 | 左侧常驻工作台入口，集中访问新建笔记、合集、知识库、批量任务、用量监控和智能体管理。 |
| 批量任务 | 以 B 站 / YouTube 视频流浏览、搜索、分页、分区、关注 UP 主与处理队列为核心，可将多个视频连续生成笔记。 |
| 处理队列 | 点击视频标题即可加入队列；支持缩略图 / 标题视图、进度追踪、已处理标记和重新加入。 |
| 合集与预览 | 创建合集、归档笔记、三栏查看与预览；预览中可继续校对、编辑、导出和管理笔记。 |
| 知识库 | 将已生成笔记沉淀为可检索资料，并可进行知识库问答。 |
| 智能体管理 | 集中管理 AI 解析、校对、知识库问答等智能体；可为不同任务选择模型、标签、Skills 与高级 API 参数。 |
| 模型与用量 | 支持 MiniMax CN、DeepSeek 等供应商；可查看云端 API 用量，并让当前选定模型承担校对等后续操作。 |
| 笔记校对 | 原文疑点以红色高亮；点击可在右侧校对栏查看 AI 修正建议，而不是直接覆盖原稿。 |
| 输出控制 | 笔记语言支持中文 / 英文；批量任务复用“新建笔记”的语言、目录、截图、总结、视觉理解和风格配置。 |
| 智能教程 | 原“教程”升级为“智能教程”：先规划读者目标、关键判断与可执行路径，再生成可复做的教程，并对自动转写中的高置信度术语错误进行语义校正。 |
| 本地部署体验 | 桌面安装版无需 Docker；内置后端与 FFmpeg，运行资料保存在当前用户目录，并会检测 GitHub Releases 更新。 |

## 下载与安装

请前往 [Releases](https://github.com/987161661/bilinote-V/releases) 下载最新的 Windows 安装包（`.exe`），双击后按向导安装即可。

无需安装 Docker、Python、Node.js 或 Git。

## 首次使用

1. 启动 **BiliNote 威力加强版**。
2. 在“AI 模型设置”中添加你自己的模型供应商与 API Key。
3. 如需本地音频转写，首次使用时按提示下载 Whisper 模型。

笔记、截图、模型、账号授权与配置仅保存在当前用户电脑的 `%LOCALAPPDATA%\\BiliNote-Power`，不会写入安装目录。

## 更新

应用会在启动时检查此仓库的 Releases。存在新版本时，右下角会显示“发现新版本，立即更新”按钮；点击即可下载新版安装包。

当前版本：`0.1.0`
